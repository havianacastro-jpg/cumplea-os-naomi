# Cumpleaños de Naomi

Página de cumpleaños para Naomi, creada con mucho amor por Hagot.

## Cómo verla
Abre `index.html` en el navegador, o publícala con GitHub Pages (Settings > Pages > Deploy from a branch > main).

## Fotos
Las fotos van en la carpeta `images/`:
- `images/foto-1.jpg` — foto favorita de Naomi
- `images/foto-2.jpg` — foto de Hagot y Naomi juntos

Reemplaza esos archivos por las fotos reales con el mismo nombre y la página las mostrará.

## Editar
Abre esta carpeta en VS Code y edita `index.html` (textos, colores, mensajes).
